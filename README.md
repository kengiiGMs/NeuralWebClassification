# NeuralWebClassification
Este repositório contém dois projetos de aplicação web que utilizam redes neurais para realizar classificações com base em dados fornecidos pelo usuário

## 📌 Projetos incluídos

## 🍎🍊 Apples And Oranges
Uma aplicação web que recebe as medidas de uma fruta e informa se ela é uma maçã ou uma laranja, com base em um modelo de rede neural treinado.

## 🌸 Iris
Uma página web que recebe as medidas de uma flor Iris e prevê sua espécie (Setosa, Versicolor ou Virginica) utilizando um modelo de rede neural treinado.
