# Modelo de Rede Neural (Iris 🌸)
Foi desenvolvida uma página web capaz de ler as medidas de uma flor Iris e prevê sua espécie (Setosa, Versicolor ou Virginica) utilizando um modelo de rede neural treinado.

## Tecnologias usadas
* Python
* Flask
* NumPy
* Joblib
* Scikit-learn

### Rodar o projeto 
1. **Python:**
   - Certifique-se de ter o Python instalado e configurado corretamente em seu ambiente de desenvolvimento.
   
   <br>

<b>Comandos:</b> 

Instalar dependências do projeto:

``` 

pip install -r requirements.txt

``` 

Iniciar o projeto:

``` 

python app.py

```
