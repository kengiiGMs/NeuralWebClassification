# Modelo de Rede Neural (Apples and Oranges 🍎🍊)
Foi desenvolvida uma página web capaz de ler as medidas de uma fruta e, por meio de um modelo de rede neural previamente treinado, classificar se a fruta é uma laranja ou uma maçã.

## Tecnologias usadas
* Python
* Flask
* NumPy
* Joblib
* Scikit-learn

### Rodar o projeto 
1. **Python:**
   - Certifique-se de ter o Python instalado e configurado corretamente em seu ambiente de desenvolvimento.
   
   <br>

<b>Comandos:</b> 

Instalar dependências do projeto:

``` 

pip install -r requirements.txt

``` 

Iniciar o projeto:

``` 

python app.py

```
